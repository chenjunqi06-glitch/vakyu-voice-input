## 日期、时间、算式

| 输入 | 结果 |
|---|---|
| `rq` / `sj` / `xq` | 当天日期（`2026年9月3日`、`2026-09-03`）、当前时间（`19:06`、`19点06分`）、星期，插在首选之后 |
| `v1+2` | 算式：出 `3` 与 `1+2=3`，支持 `+ - * / ^`、括号、小数 |
| `v123` | 中文数字：一百二十三 与 壹佰贰拾叁；金额：一百二十三元整 与 壹佰贰拾叁元整 |
| `v123.5` | 小数读法：一百二十三点五 与 壹佰贰拾叁点伍；金额：一百二十三元五角 与 壹佰贰拾叁元伍角（小数最多两位，到分） |
| `u4e00` | 按十六进制码点输入字符：一；`u+1f600` 出 😀 |

以 `v` 开头后，数字与运算符均进入算式，不再用于选词或翻页；选第二项用 `↑` / `↓` 加 `Space`，`Enter` 将所敲内容原样输出。
以 `v` 开头的英文词（`very`）不受影响，仍给出英文候选。

`v` 与 `u` 两个前缀键可在「偏好设置 → 快捷键」修改，只能是 v、u、i 三个字母（它们不作为任何拼音的开头）。
双拼下 `v` / `u` 是音节键，改用 `Shift`+`V` / `Shift`+`U` 开头（`V1+2`、`U4e00`）。

`u` 之后接拼音为 [问字](../cloud/question-and-translate.md)，需打开云联想；`?` 缺省只是问号，可在「快捷键」页勾选让它也进入问字。

## 中英混输

中文模式下无需切换：

- 整段输入为英文词时直接给出英文候选。拼音不成立时（`hello` 只能切成 `he l l o`）英文排第一，拼音成立时（`china`）英文排第二。
  勾选「偏好设置 → 通用」的「输入拼音时中文候选排在英文词前面」后英文固定排第二（`hello` 先 荷兰咯 再 hello，`key` 先 可以 再 key），
  `Space` 上屏的仍是中文，按 `2` 选英文；没有中文候选时（`github`）英文仍排第一。
  专名按正确大小写上屏：`windows` → **Windows**，`github` → **GitHub**，`python` → **Python**。
- 拼音不成立且不少于 3 个字母时补全前缀：`compa` → company / companies / compared。
- 一句拼音末尾接一个英文词时，整句直接包含该词：`woxiangxuehaorust` → 我想学好rust，`wodeid` → 我的ID，`woyongvim` → 我用vim，`yongwindows` → 用Windows。
  拼音行显示 `wo'xiang'xue'hao'rust`，`Space` 上屏整句。该英文词需在词表中（用户自己输入过的也算，见 [英文模式](english-mode.md)）。
  `database` 这类同时可读作拼音的输入，按两种读法的通顺程度排序：我的database 排第一、我的大塔巴瑟 排第二；
  `womenqubeijing` 只给出 我们去北京。`fan`、`to` 这类短词按拼音处理；可纠正为通顺拼音的输入错误（`shiide` → 是的）不视为英文。
  英文词只识别句末，`wozaidebugzhege` 这类位于句中的暂不支持（可先上屏前面的中文，再打英文词）。
- **中英混杂词**（字母 + 汉字）直接按「字母 + 拼音」打：`cpan` → C盘，`bzhan` → B站，`dpan` → D盘，`txu` → T恤，`agu` → A股，`xguang` → X光。
  U盘 因 `u` 是问字前缀，打 `youpan`（与 优盘 同读音，U盘 排前）。它们也能进整句：`wozaibzhan` → 我在B站。
- 输入拼音时输入半角标点（`-` `,` `.` `?` 等，翻页键除外）会先上屏当前高亮候选，再输出标点；没有中文候选时才进入**英文直输**。已经进入直输段后，`no-way` `hello,` 整段原样显示，之后的字符原样追加，
  `Space` / `Enter` 原样上屏（空格字符也一并输出），因此中文模式下可直接输入 `hello, world?`。

## emoji

前几个候选中有对应 emoji 的词，emoji 紧随该词之后，右侧标注对应的词：`ku` → 哭 😢 😭，英文模式 `smile` → smile 🙂 😊。
每个词最多两个，一次最多三个，上屏不记录学习。

## 语音与英语跟读（Windows）

点击输入框，按住语音键（默认左右 Alt 都可用）说中文，松开后将识别结果填入原输入框，不会自动发送。语音键可在 **设置 → 快捷键** 中修改，后台运行时无需为每个软件单独设置。

对微信等自绘输入区，新版会尝试通过当前输入法保存的原插入位置填入，而不依赖控件是否公开无障碍编辑信息。需要该软件已经加载新版输入法组件；仍加载旧版的软件不会被强制注入新代码。输入位置改变、只读或私密输入区会拒绝填入；若提示“没有确认填入结果”，先检查正文，避免重复输入。

想顺便练习英语，可以开启同页的 **英语跟读练习**。它默认关闭；开启后，中文口述结束先显示对应的英文译句，默认先播放一遍本机示范，再自动开始跟读。读完整句后才填入原中文，按 `Esc` 可取消。“跟读示范朗读”有独立开关，关闭后直接开始跟读录音。

浮窗显示当前英文词、已读进度、等级和经验。第一次从新手开始，随着本机当前 Windows 用户完成练习逐步升级；新手示范较慢，文字匹配有有限容错。经验只在整句完成后增加，取消或失败不扣分。颜色进度用于提示识别匹配，不是发音评分。

翻译需要先配置云服务；录音、示范播放和跟读识别均在本机完成。完整流程与升级规则见 [英语跟读练习](../getting-started/keys.md#英语跟读练习)。

音波随麦克风实际音量变化；跟读浮窗还显示“刚听到”的结果。新手的短句和首尾词允许近音匹配，人名支持按拼音音节核对连写或拆词；有识别偏差时可继续补读，仍需读完整句才填入中文。

跟读时点英文单词可查看本地中文释义和音标，点“播放发音”使用 Windows 已安装的英语声音。查询不联网、不消耗 API token；未收录的词会明确提示。播放单词时暂时关闭麦克风，防止示范声音被算作你的跟读，播放后继续原进度。只查看词卡不会中断收音。

识别卡住时，可点“再试一次”“跳过此词”或“我读对了”。点击词卡或其他位置不会关闭练习；只有按 `Esc`，或读完并成功填入中文后才关闭。填入失败会保留原句供重试，仍不会自动发送。

微信等自绘输入框可通过当前宿主的 Miracle 输入法编辑接口接收语音文字；未收到确认时会提示先检查输入框，避免重复填入。新版组件安装后，已运行的软件可能仍使用它之前加载的旧组件。
