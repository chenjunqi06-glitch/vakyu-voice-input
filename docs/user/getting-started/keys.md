按键按各自系统的习惯设计，少数功能仅限指定平台。表中 `⌥` 为 Option，`⌘` 为 Command，`⌃` 为 Control，`⇧` 为 Shift；
「—」表示该平台没有此键。

## 切换模式

| 操作 | macOS | Windows |
|---|---|---|
| 中 / 英切换 | `Caps Lock` | 单击 `Shift`（设置里还可勾单击 `Ctrl`、`Ctrl + Alt + Space`，可多选）；系统的 `Ctrl + Space`；或点击任务栏 / 悬浮状态条上的「中 / 英」 |
| 直接输入大写英文 | 英文模式下按住 `⇧` | `Caps Lock` 亮起（中英模式均可） |
| 输入拼音时临时输入一个大写字母 | `⇧ + 字母`：拼音原样上屏，再输入该大写字母；设置里可改成「进组句」：大写按小写参与匹配，`Cpan` 与 `cpan` 一样能出「C盘」 | 同左 |
| 切换全角 / 半角标点 | 中文全角、英文半角，不可更改 | 点击悬浮状态条上的「，。」格，中英各记一份 |
| 切换到其他输入法 | `⌃ + Space`（系统） | `Win + Space`（系统） |

Windows 的「中 / 英切换」键在设置里勾选，可以多选：单击 `Shift`、单击 `Ctrl`（打字时容易误触 `Shift` 的话）、`Ctrl + Alt + Space`；一个都不勾就只剩按钮能切。中英模式所有应用共用一份。关掉「内置英文模式」后，切换键与任务栏、悬浮状态条上的「中」「英」都不再切到英文，需要英文时用 `Win + Space` 切到别的输入法。

Windows 的主键盘数字和常用标点按当前系统键盘布局识别；非美式布局的字母、AltGr 和组合音符输入仍有局限。

Windows 上中 / 英的切换键可以勾选（设置 → 通用，配置 `[shortcut] switch_mode`，可多选）：**单击 Shift**（缺省，与微软拼音一致）、
**单击 Ctrl**（Shift 老是误触时用）、**Ctrl + Alt + Space**（组合键，最不易误触）；一个都不勾就只剩任务栏 / 悬浮状态条上的「中」「英」按钮能切。
改完**立刻生效**；没在打字时 Shift 在其他组合键里的作用不受影响。系统自带的 `Ctrl + Space`（输入法/非输入法切换）也能切中英，与微软拼音一致，不在勾选项里。

还可以整个关掉**内置英文模式**（设置 → 通用，配置 `[general] english_mode`）：关掉后 Miracle 固定中文模式，
切换键与任务栏、悬浮状态条上的按钮都不再切到英文，需要英文时用 `Win + Space` 切到别的输入法。
详见 [英文模式](../input/english-mode.md)。

## 语音输入（Windows）

Vakyu 后台运行时，在普通软件的输入框内单独按住 **左 Alt**，等浮窗显示“正在聆听”后说普通话。语音浮窗固定在当前输入框所在屏幕的底部中央、任务栏上方，实时显示识别中的文字，文字变多时向上展开；松开 Alt 后立即收起，最后的识别结果完成后一次输入到原来的输入框。普通语音与跟读是两个独立入口：即使开启跟读，左 Alt 仍直接填入原话，不调用翻译服务。持续按住期间不设五分钟自动截止，约千字的长篇口述和中途思考停顿会继续累积，直到松开才结束。浮窗只预览最近几行，前面的文字仍保留在本轮全文中。

录音浮窗从准备麦克风时就标明本轮是“普通语音”“英语跟读”还是“中文跟读”，并分别提示松开后直接填入、进入英文跟读或进入中文跟读。跟读入口录的是原话：学习英语时先说中文，学习中文时先说英文；读完译句才填入原话。模式标签与麦克风准备、聆听或错误状态分开显示，实时文字和音波刷新时仍保持可见。

短按 Alt、Alt + Tab、Alt + F4 等组合键保留原用途。正在选拼音候选时，请先完成选词再按住 Alt；从开始录音到文字填入之前，按其他键、点击其他位置或切换窗口会取消本次语音，避免迟到的文字写错位置。

录音旁边的音波跟随麦克风实际音量变化，说话时起伏、安静时回落；即使暂时还没识别出文字，也能看到收音变化。松键、取消或示范播放期间不显示录音波动。

安装语音模型后，使用本机运行的流式识别与系统默认麦克风；模型会提前加载，普通语音输入仅在按住 Alt 时打开麦克风，跟读练习会在示范朗读结束后自动开启跟读录音。两个学习方向共用中英双语模型，无需额外模型或显卡。未安装模型包时使用 Windows 自带的简体中文语音识别，此时仅支持普通中文口述。识别文字会随短语更新，不保证每个字立即出现。此功能不上传录音、不保存音频文件，也不会自动补写后半句。

在 **设置 → 快捷键 → 普通语音转文字按键** 中，可以选择仅左 Alt（默认）、仅右 Alt 或左右两侧 Alt，并恢复默认左 Alt；“按住说话”是语音总开关，“启动灵敏度”可调整长按时间，默认 100 毫秒。开启跟读后这个独立入口仍可用。若与跟读快捷键重叠，保存时提示冲突并保留原值；例如普通右 Alt 与右 Ctrl＋右 Alt 的组合前缀冲突，需要先改跟读键。旧版“双侧 Alt”设置与右侧组合配合时，右 Alt 留给跟读组合、左 Alt 用于普通语音。保存后自动生效，无需重开聊天软件。

语音按键、识别、浮窗与文字填入统一由后台管理，不依赖每个软件加载新版输入法，也不要求切换到 Miracle。已经打开的软件和以后安装的软件都使用同一个入口，无需逐个重开、登记或安装插件。更新语音后台会取消正在录制的一段，请等后台恢复后松开 Alt 重新说；拼音输入法基础组件的更新可能仍需宿主重新加载，但不影响这种独立语音入口。

需要先点击可编辑的输入框。密码框、只读区域、锁屏和系统安全确认界面不可使用；未提供标准文字输入能力的特殊控件可能暂不支持，会在按住时提示。未带受信任签名的本地构建不能向管理员权限的软件填字，可在普通权限软件中使用。收到文字后由你确认内容，再决定是否发送。

使用普通语音入口时，松开后中文会自动填入开始录音的输入框，无需复制粘贴；不会替你按发送键，也不会进入跟读练习。

也可在配置文件的 `[shortcut]` 下设置 `voice_input = false` 关闭，`voice_key = "right_alt"` 改用右 Alt，或设置 `voice_hold_ms = 180` 调整长按时间（100–1000 毫秒）。

### 中英跟读练习

在 **设置 → 快捷键 → 启用跟读练习 / Reading practice** 中开启。此功能默认关闭，可随时关闭。开启前，在「设置 → 云服务」配置可用的翻译服务，例如 DeepSeek。

同页的 **学习英语 / Learn English** 决定方向，默认开启；关闭这个方向开关会改为学中文，不会关闭跟读练习。

| 学习英语开关 | 口述原文 | 跟读内容 | 完成后填入 |
|---|---|---|---|
| 开启（默认） | 中文 | 英文译句 | 原中文 |
| 关闭 | 英文 | 中文译句，附拼音提示 | 原英文 |

两个方向共用 **跟读快捷键**，出厂默认按住 **右 Ctrl＋右 Alt**。可以点“按下新的快捷键”，按住 `右 Ctrl + 右 Alt` 或 `Ctrl + Alt + E` 等组合键，全部松开后点击“保存”，或点“恢复默认”还原右 Ctrl＋右 Alt。录好后需要换键时，点击“重新录入快捷键”。保存成功立即生效，退出或重启后仍保留；切换学习方向不会重置已保存的快捷键。关闭“启用跟读练习”只关闭跟读入口，普通语音入口继续可用。每轮按下时锁定入口，不会在松键时根据跟读开关把普通语音改成跟读。

`右 Ctrl + 右 Alt` 的按下顺序不限，两键同时按住才录音，松开任意一键结束。左侧按键与 AltGr 的左 Ctrl 前缀不会触发这组快捷键。

允许带 Ctrl、Alt 或 Win 的字母 / 数字 / 空格组合键、F 功能键、单独左右 Alt，以及 `右 Ctrl + 右 Alt`；单独字母、数字、空格、`Shift + 字符`、`Alt + F4` 以及系统保留的 F12 不能选。单键会占用该键的原用途，推荐使用组合键。不支持的纯修饰键组合在松开后会显示原因。录入期间可按 Esc 或点“取消录入”，离开设置窗口或 30 秒未完成也会取消。

保存前会检查是否与普通语音入口重叠，并尝试向 Windows 注册快捷键。被系统或其他程序注册占用时提示“该快捷键产生冲突，请更换”，保留原快捷键，不覆盖配置。此检查可以发现系统级热键注册冲突，不能完整区分左右修饰键，也不能识别软件只在自己窗口内处理的快捷键、部分底层键盘监听、键盘驱动重映射或之后才启动的软件行为。开启跟读时 Vakyu 持有系统注册；关闭跟读或语音功能后释放。跟读注册失败不会停用独立普通语音入口。配置项默认为 `[shortcut] voice_practice_shortcut = "right_ctrl+right_alt"`，其他示例为 `"ctrl+alt+e"`。

1. 按住跟读快捷键，学英语时说中文，学中文时说英文；松开后保留原文，暂不填入输入框。
2. 原文下方显示所学语言的译句，先听一遍本机示范朗读。示范期间麦克风保持关闭，结束后短暂停顿，再自动开始跟读录音，无需继续按住快捷键。
3. 等浮窗显示“正在录音”后，按显示顺序读译句。已通过的内容由浅色变深色，本轮内保留进度；读错、停顿或识别文字回改后，只需从当前未通过的词继续，不必从头重读。当前位置有文字提示和下划线，长句会随进度滚动。学中文时可参考拼音；未完成整句练习时，原文不会填入输入框。
4. 全句完成后关闭录音，并将最初口述的原文填入原输入框：学英语填入原中文，学中文填入原英文。是否发送仍由你决定。

“继续补读”保留通过进度并重新开始收音；想主动重练时，点“整句重读”才清空本句进度，从第一个词开始。两种操作都复用当前译文，不增加翻译请求。也可以自然重复已读部分，再接着往下读。句中同一个词出现在不同位置时，仍需按各自的位置朗读；Esc 取消或开始新一轮会清空本轮进度。

**设置 → 快捷键 → 跟读示范朗读** 默认开启，可单独关闭，按学习方向使用本机英语或中文声音。关闭后译句准备好就直接进入跟读；示范暂不可用时也会提示并进入直接跟读，仍需完成练习才会填入原文。

点击译句中的词可查看本地词卡：英文词显示中文词义与可用的音标，中文词显示英文词义与拼音；“播放发音”使用本机对应语言的声音。查询兼容常见英文词形，但本地词表不能覆盖所有生僻词与人名。没有结果会明确提示，不会编造释义，也不会为词卡额外调用翻译服务。

练习从“新手 Lv.1”开始，浮窗上方显示等级与经验进度。新手阶段示范较慢，对少量常见识别偏差更宽容；随着完成练习积累经验，示范语速和文字匹配要求逐渐提升。

| 等级 | 累计经验 |
|---|---|
| 新手 Lv.1 | 0–119 XP |
| 进阶 Lv.2 | 120–499 XP |
| 挑战 Lv.3 | 500 XP 及以上 |

每完成一轮，按练习长度获得经验，单轮最多 60 XP；取消、未读完或识别失败都不会扣经验，也不会增加经验。英语与中文分别积累经验，切换方向不会覆盖另一份进度。达到升级条件后，从下一轮开始使用新等级，本轮不会突然变难。

按 `Esc` 可取消本轮练习。切换学习方向或关闭练习总开关也会取消尚未完成的一轮；下一轮按新方向重新录音，不会填入上一轮的迟到结果。浮窗仍位于屏幕底部中央、任务栏上方，并在跟读期间持续显示。

练习进度按本机当前 Windows 用户保存，只记录经验和完成次数，不记录句子或音频，不使用 IP 判断用户或水平。每段只将本次口述文字发送给已配置的翻译服务一次，不发送光标附近内容；示范播放、跟读识别和词卡查询在本机完成，不上传音频。切换方向不增加每段翻译的请求次数，词卡查询不消耗 API token。翻译或识别失败时不会跳过练习自动填入。

配置文件的 `[shortcut] voice_english_practice` 是跟读总开关；`voice_practice_learn_english = true` 表示学英语，`false` 表示学中文。两个设置相互独立，修改后立即生效并保存。

跟读的颜色进度表示识别文字与译句的匹配情况。新手和进阶阶段有有限的文字容错，但这不是口音、音素或发音质量评分；请尽量按完整译句朗读。

新手模式按读音接近程度匹配常见英语词，短句和首尾词也可使用口音容错。中文原句中的人名会核对拼音音节，兼容连写、拆词，以及识别器把名字写回汉字的情况；仍需按顺序读到完整名字，数字和否定词不能省略。读错后可以从当前词继续补读。

跟读时浮窗的“刚听到”显示最新识别结果；卡住时可对照下划线词继续读，不必猜测麦克风是否收到声音。中英混杂的识别片段不会清空已匹配进度，但译句内容仍须按顺序读到。识别会参考本轮译句，提示仅用于本机当前这轮练习，下一轮普通口述不会继承。

### 注音模式（Windows）

「设置 → 通用」打开「大千注音」后，组句中的按键改为：

| 操作 | Windows |
|---|---|
| 上屏高亮候选 | `Enter` |
| 将注音符号原样上屏 | `Shift + Enter` |
| 一声 / 轻声 | `Space` |
| 声调与符号（进入组句，不选词） | 数字键，`-` `;` `,` `.` `/` |

大千键盘布局把数字键与 `- ; , . /` 都分给了注音符号和声调，所以注音模式下这些键不再选词，选词用 `Enter`；`Space` 是一声。macOS 暂无注音模式。

> **五笔（形码）**：组句时敲的是字根编码，没有音节的概念，所以「删到音节边界」「拼音行分段」这些不适用，
> 左右键按单个字母移动光标。整句输入、简拼、模糊音、拼写纠错在五笔下都不生效，
> `v` / `u` / `i` 也不再是模式键（它们是字根键）。选词、翻页、上屏、删除候选与拼音一致。
> 拼音方案与五笔**同时开着**是混输：两边都出候选、编码打全的五笔词在前，见 [模糊音与输入方案](../input/fuzzy-and-shuangpin.md)。

翻页键对可改为 `,` `.` 或 `-` `=`：「偏好设置 → 快捷键」。

## 英文模式下

| 操作 | macOS | Windows |
|---|---|---|
| 选择高亮候选 | `Space`、`Tab` | `Space`、`Tab` |
| 选择第 N 个候选（当前页没有第 N 个时，数字作为内容接在所敲字母后，如 `gpt6`） | 数字键 | 数字键 |
| 移动高亮 / 翻页 | `↑` / `↓`、翻页键 | `↑` / `↓`、翻页键 |
| 原样输出所敲字母 | `Enter`、标点 | 同左 |

没有候选时数字直接接在字母后（`xq1`）；带数字的标识符先按 `Enter` 输出字母再敲数字。

## 译词与删除候选

| 操作 | macOS | Windows |
|---|---|---|
| 上屏第 N 个候选的第一条译词 | `⌥ + 数字` | `Ctrl + 数字` |
| 上屏第二条译词（候选右侧有两条时） | `⇧⌥ + 数字` | `Ctrl + Shift + 数字` |
| 删除第 N 个候选 | `⇧ + 数字` | `Shift + 数字` |

仅在输入拼音时有效。三组修饰键在「偏好设置 → 快捷键」（Windows：「设置 → 快捷键」）录制修改；
macOS 上应避开 `⌃ + 数字`（系统切换桌面）与 `⌘ + 数字`（应用切换标签页），Windows 上 `Alt + 数字` 会被应用作为菜单快捷键截获。
删除候选的说明见 [译词与生词](../learning/translation.md#删除不需要的候选)。

## 云联想

| 操作 | macOS | Windows |
|---|---|---|
| 翻译应用中选中的文字 | `⌃⌥T` | `Ctrl + Alt + T` |
| 翻译结果：替换选区 | `Enter` / `Space` / `1` | 同左 |
| 翻译结果：保留原文 | `Esc` | `Esc` |
| 问字 | 输入 `u`（双拼下 `Shift`+`U`）再输入拼音；勾选「敲 ? 也进入问字」后未输入拼音时输入 `?` 再接拼音同样可用 | 同左 |

均需先打开云联想，见 [问字与翻译](../cloud/question-and-translate.md)。翻译快捷键可修改；Windows 上修改后需切换到其他输入法再切回 Miracle 才生效。

## 前缀键

| 输入 | 结果 |
|---|---|
| `rq` / `sj` / `xq` | 日期 / 时间 / 星期 |
| `v` + 算式或数字 | 算式结果、中文数字与金额（`v123.5` → 壹佰贰拾叁元伍角）；双拼下以 `Shift`+`V` 开头 |
| `u` + 十六进制 | 该码点对应的字符；双拼下以 `Shift`+`U` 开头 |
| `u` + 拼音 | 问字（需打开云联想）；`?` + 拼音需在「快捷键」页勾选后可用 |

两个平台相同，详见 [快捷输入](../input/shortcuts.md)。`v` 与 `u` 可在「快捷键」页改为 v、u、i 三者之一。

## Mac 全局语音与跟读

Mac 完整语音开发版默认按住左 `Option` 做普通语音，松开直接填入；右 `Control`＋右 `Option` 是独立口语跟读入口，需先启用跟读。普通语音不受跟读开关影响。`Esc` 取消。跟读快捷键在“语音与跟读设置”里录入并检测系统注册冲突；学习方向另有开关。详见 [Mac 语音与双向跟读](macos-voice.md)。此移植仍需 Mac 真机验收。

## Linux（Fcitx5）

单击 `Shift` 切换中英；按住 `Shift` 输入字母不会切换。`Space`、`1` 至 `9` 以及候选点击选词，
全拼 / 双拼下 `Enter` 原样输出，`Backspace` / `Delete` 编辑，`Esc` 取消，方向键移动高亮或光标。
`[` / `]` 和 `PageUp` / `PageDown` 翻页；翻页键可在配置文件修改。

Linux 的 `Tab` 规则：没有组句时 `Tab` / `Shift + Tab` 交给应用；中文组句中 `Tab` 接受整句补全，
无补全时下一页；英文组句中 `Tab` 选择高亮候选；组句中的 `Shift + Tab` 始终上一页。
Linux 当前提供本地候选，尚无云端整句补全。裸问号的既有还原规则优先。

数字选择当前页对应候选；当前页没有这一格时数字接入缓冲区，`hao6` 回车可原样输出。
进入英文直输段后数字和标点继续追加，`gpt-6` 后按空格得到 `gpt-6 `。
英文候选开启时，数字、翻页键和空格同样可选词，空格选词后保留一个空格。
小键盘运算符保持半角；关闭 NumLock 时按导航键处理。

`[general] shift_letter = "compose"` 可让大写字母参与中文组句，默认原样输入大写英文。
双拼下 `Shift + V` / `Shift + U` 分别进入表达式 / 码点输入，入口字母可在 `[shortcut]` 修改；问字的云服务暂未提供。
大千注音（`[general] scheme = "zhuyin"`）下，数字及 `- ; , . /` 输入符号和声调，空格补一声，再按空格可选词；
`Enter` 选高亮，`Shift + Enter` 原样输出注音。

Linux 缺省 `Alt + 数字` / `Alt + Shift + 数字` 上屏第一 / 第二条译词，`Shift + 数字` 删除候选，
可在配置文件 `[shortcut]` 修改。安装与配置位置见 [Linux](linux.md)。
