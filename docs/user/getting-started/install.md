## macOS

**系统要求**：macOS 13 或更新。Apple Silicon 与 Intel 各有一个安装包；不确定机型时，点左上角  → 「关于本机」，查看「芯片」一行。

1. 下载 `qingjian-<版本>-macos-arm64.pkg`（Apple Silicon）或 `qingjian-<版本>-macos-x86_64.pkg`（Intel），双击安装，需要管理员密码。
2. 测试版尚无 Apple 开发者签名，首次打开会被系统拦截：到「系统设置 → 隐私与安全性」，在底部点「仍要打开」，再安装一次。
3. 安装完成后，输入法菜单中出现「Miracle」。

若未出现，到「系统设置 → 键盘 → 输入法 → 编辑 → +」，在「简体中文」下添加「Miracle」；仍未出现则注销后重新登录。

安装后：

- 菜单栏右上出现「中 / 英」状态项，点击可打开输入法菜单与偏好设置。
- 偏好设置在输入法菜单中，修改即时生效，没有「保存」按钮。
- 首次使用先到「偏好设置 → 通用」选择学习语言（英语 / 日语 / 西班牙语），候选旁的译词即为该语言。

## Windows

**系统要求**：原生 x64 的 Windows 10 22H2（19045）或 Windows 11。此安装包不支持 32 位 Windows、Windows ARM 或 macOS。安装包包含设置界面运行库、独立 Python、中英离线语音模型与词典，不需要另装 Python、Rust 或显卡计算环境。

1. 下载 `vakyu-<版本>-windows-x86_64-setup.exe`，双击安装，按提示授予管理员权限。默认目录为 `C:\Program Files\Qingjian`，用于兼容之前安装的数据路径。
2. 安装向导会一并安装所需的微软运行库；无需额外下载模型。当前包尚无公开受信任的代码签名，Windows 可能显示发布者未验证或 SmartScreen 提示。仅使用提供者交付且校验值一致的文件；无需导入证书或关闭系统安全功能。
3. 完成后后台自动运行；可勾选打开「Vakyu 设置」。首次加载语音模型在较慢的电脑上可能需要几十秒，设置中显示就绪后即可使用。

安装后：

- 任务栏右下显示当前为「中」或「英」；桌面上可另开一条悬浮状态条，见 [英文模式](../input/english-mode.md#悬浮状态条（Windows）)。
- 设置在开始菜单的「Vakyu 设置」，也可右击任务栏通知区域的 Vakyu 图标进入。
- 首次使用先到「设置 → 通用」选择学习语言（英语 / 日语 / 西班牙语）。
- 普通语音默认开启：点输入框，按住左 Alt 说话，松开后文字自动填入，不自动发送。语音在本地处理，不消耗翻译 API token。麦克风须已连接，并允许桌面应用访问。
- 口语跟读默认关闭：填入使用者自己的翻译 API 密钥，再开启跟读；按住右 Ctrl＋右 Alt 说话，松开后翻译并跟读，通过后填入原话。可保持云联想关闭，以减少 API 用量。安装包不包含提供者的密钥、个人词库、记录或音频。
- 输入法通过 `Win + Space` 选择；普通语音由全局后台处理。**升级后，已加载旧输入法组件的应用可能需要重新打开**，新启动的全局语音后台无需等待这些应用重启。设置项修改按界面提示生效。

若 Vakyu 未出现在输入法列表，可在 Windows「语言与区域 → 中文（简体）→ 语言选项 → 添加键盘」中添加，或注销后重新登录。安装器不会移除其他键盘，也不会强制修改默认输入法。

**兼容范围**：当前分发包不使用仅本机信任的证书，因此不具有跨权限的 uiAccess 能力。以管理员权限运行的软件、密码框、安全桌面和部分系统面板不保证支持语音填入或浮窗显示。示范朗读使用 Windows 已安装的语音，缺少目标语言音色时需在系统设置中添加。没有可用麦克风时仍可使用键盘输入。

Vakyu 当前未配置自动更新服务；更新请从原提供者取得新的完整安装包，不会自动下载上游项目版本。

登录后 Vakyu 在后台静默启动，不自动打开设置或命令行窗口。多个应用同时唤起输入法时只保留一份后台和一个托盘图标；后台恢复不会抢走当前窗口焦点。升级前遗留的旧托盘图标可能需要鼠标经过一次，由 Windows 清理。

## 升级与卸载

升级时直接安装新版安装包，学习数据与设置均保留。卸载见 [卸载](../help/uninstall.md)。
