Vakyu 提供普通语音输入与口语跟读两个独立入口。普通语音只负责把话变成文字；跟读把本轮原话翻译成所学语言，完成练习后再填入原话。两个入口都不会自动发送消息。

## 1. 安装与首次启动

适用系统：Windows 10 22H2（19045）或 Windows 11，Intel / AMD x64。当前安装包不支持 Windows ARM 和 32 位 Windows，也不支持多个 Windows 登录会话同时运行。

1. 在 [Vakyu Releases](https://github.com/chenjunqi06-glitch/vakyu-voice-input/releases) 选择测试版，展开 Assets，下载以 `windows-x86_64-setup.exe` 结尾的文件。`Source code` 与 `source.zip` 是源码，普通使用无需解压它们。
2. 运行安装程序，按 Windows 提示授权管理员权限，阅读许可并完成安装。模型、词典、Python 和所需运行库已经包含，不需要手动安装开发环境。
3. 从开始菜单搜索「Vakyu 设置」，或右击任务栏右下角的 Vakyu 图标，选择「进入设置…」。若图标折叠，先展开通知区的上箭头。
4. 在 Windows「设置 → 系统 → 声音」选好输入设备；在麦克风隐私设置中允许桌面应用访问麦克风。
5. 等待本地模型加载完成，再进行首次口述。CPU 识别不要求独立显卡，初次准备与识别速度取决于电脑和设备状态。

安装后后台随用户登录启动。拼音输入用 `Win + Space` 切换到 Vakyu，语音入口只要求后台运行。安装不会删除其他输入法，也不会替用户选择默认输入法。

公开测试包尚无可信的发布者签名，Windows 可能显示「未知发布者」或 SmartScreen 提示。核对本仓库 Release 与随附 SHA-256 校验文件；组织管理的电脑还需符合其软件安装策略。无需为 Vakyu 关闭杀毒或系统安全功能。

## 2. 普通语音输入：无需联网或密钥

1. 点击需要输入文字的文本框。
2. 按住键盘**左 Alt**，浮窗显示「普通语音」及收音状态后开始说中文。
3. 说话时可看到识别预览和随实际音量变化的音波。保持按住可以连续口述，中途停顿不会自动结束。
4. 松开左 Alt，最终识别结果填入开始录音的输入框。检查内容后自行发送。

`Esc` 取消本轮。录制普通语音时，点击其他位置、切换窗口或继续打字可能取消本轮，以防文字填入错误位置。请在填入完成前保持原输入位置。

短按 Alt、`Alt + Tab` 和 `Alt + F4` 保留系统用途。默认长按判定为约 100 毫秒，模型和设备仍可能需要准备时间。若输入法正在选词，先完成选词再开始语音。

普通语音不会翻译、续写后半句，也不消耗 API token。即使已经开启跟读练习，左 Alt 仍直接填入识别文字。

## 3. 配置跟读翻译

跟读默认关闭，需自行准备可用的翻译 API。Vakyu 不提供公共密钥或免费云端额度。

打开「设置 → 云服务」，填写：

| 字段 | 填写方式 |
|---|---|
| 接口地址 | 服务商提供的 OpenAI 兼容接口基础地址，不追加 `/chat/completions`；使用 DeepSeek 时可填 `https://api.deepseek.com` |
| 模型 | 填该服务商当前支持且自己的账户可调用的模型标识，不填网页产品昵称 |
| API 密钥 | 填自己在该服务商控制台创建的密钥，不要分享给他人 |

点击「测试连接」，出现成功结果后再开始跟读。测试会发送一次小请求，可能产生少量服务商费用；失败时检查密钥、余额、模型名、接口地址及网络。模型列表与价格可能变动，以服务商说明为准。

**只想在跟读时使用 token：保持「启用云联想」关闭即可。** 跟读翻译复用上方接口设置，不要求开启日常打字的云联想。「整句补全」也可保持关闭。

再打开「设置 → 快捷键」：

- 保持「启用语音输入」开启，这是普通语音和跟读的总开关。
- 开启「启用跟读练习 / Reading practice」。
- 用「学习英语 / Learn English」选择方向。
- 按需启用「跟读示范朗读」，该功能使用 Windows 本机声音。

## 4. 开始一轮跟读

| 「学习英语」开关 | 先口述 | 松键后跟读 | 完成后填入 |
|---|---|---|---|
| 开启 | 中文 | 英文译句 | 原中文 |
| 关闭 | 英文 | 中文译句，附拼音 | 原英文 |

1. 点击目标文本框，按住**右 Ctrl + 右 Alt**，按上表说原话。两键按下顺序不限，保持同时按住才录音。
2. 松开任意一键，等待翻译。原话暂不填入；浮窗标明本轮是英语或中文跟读。
3. 若启用示范，先听本机读一遍。示范期间麦克风关闭；播放结束后自动开启跟读录音，**此时不用继续按快捷键**。
4. 等到「正在录音」提示后按顺序跟读。通过的词由浅色变深色，当前词有下划线；「刚听到」显示识别结果。
5. 全句通过后，原话填入原文本框，练习浮窗关闭。发送由用户自己决定。

例如，学习英语时说「我今天要去吃饭」，等待英文译句后跟读英文；完成后文本框出现的仍是「我今天要去吃饭」。

练习中点击浮窗内外不会因点击本身关闭练习，`Esc` 可取消。请保留原输入目标；若目标关闭或状态变化导致无法安全填入，程序可能拒绝填入并显示原因。

### 读错、停顿与专有名词

已经通过的词会保留，不因停顿或识别结果修订而清空。接着读当前未通过的词即可，也可以自然重复前文。

| 按钮 | 作用 |
|---|---|
| 继续补读 | 保留已通过词，重新开始收音 |
| 跳过此词 | 跳过当前词，继续后面的内容 |
| 我读对了 | 手动放行当前词，适用于人名或识别误判 |
| 整句重读 | 主动清空本句进度，从第一个词重练 |

上述操作复用当前译文，不会为同一轮补读重新请求翻译。新一轮或取消会清空本轮进度。同一个词若在句子不同位置出现，仍按各自位置练习。

新手阶段匹配较宽容，随着经验等级增加逐步提高要求。判定依据本地识别结果与文字匹配，不能当作专业发音评分；遇到人名、口音或噪音导致误识别时，可查看「刚听到」并手动放行。

## 5. 点击词语查词与听发音

跟读时点击译句中的词，可打开本地词卡：

- 英文词：中文词义、词典中已有的音标，以及「播放发音」。
- 中文词：英文词义、拼音，以及「播放发音」。

查词不重置已通过进度，不发送词语到在线词典或另行调用翻译 API。本地词表对生僻词、人名和部分词形可能没有结果，此时会提示缺失，不会编造释义。音标并非每个词都有。

播放使用 Windows 本机中英文声音。若没有对应语言的声音，在 Windows 语言或语音设置中添加相应语音组件。没有示范音色时可以关闭示范，继续自行跟读。

## 6. 自定义快捷键与托盘开关

「设置 → 快捷键 → 普通语音转文字按键」可以选择左 Alt、右 Alt 或两侧 Alt，默认左 Alt；恢复默认后也使用左 Alt。更改后自动生效。

在「口语跟读快捷键」点「按下新的快捷键」，按下想用的组合，全部松开后保存。支持右 Ctrl + 右 Alt、`Ctrl + Alt + E`、允许的 F 功能键及单侧 Alt；不允许单独字母、数字、空格或部分系统保留键。可用「恢复默认」还原右 Ctrl + 右 Alt。

保存会检查普通语音入口重叠与 Windows 全局热键注册冲突，冲突时保留原设置。该检查不能完整识别软件内部快捷键、底层键盘监听、驱动重映射和之后启动的软件，也不能全面区分左右修饰键。单键可能占用原用途，优先使用组合键。

右击任务栏右下角 Vakyu 图标，可以快速切换语音输入、跟读练习、学习方向、示范朗读、云联想、悬浮状态条与全角标点，并进入设置。托盘「联网翻译与联想」影响云联想；它关闭时，已经配置好的独立跟读翻译仍可用。

## 7. 常见问题

| 现象 | 先检查 |
|---|---|
| 按键没有浮窗 | 后台是否运行、「启用语音输入」是否开启、实际保存的快捷键，以及目标是否可编辑 |
| 有音波，没有文字 | 模型是否就绪、Windows 选中的麦克风、收音距离与环境噪音 |
| 跟读没有译文 | 跟读总开关、学习方向，以及云服务「测试连接」结果 |
| 读过的词迟迟不通过 | 对照「刚听到」与当前词；继续补读，或对专名使用「我读对了」 |
| 有文字但不能填入软件 | 先在普通权限的文本框测试；管理员程序、密码框、游戏或自绘控件可能受限制 |
| 第一次启动慢 | 模型正在加载；先等待就绪，关闭不需要的其他重负载程序 |
| 快捷键和应用功能冲突 | 改用其他组合键，冲突检测无法覆盖所有应用内部行为 |

升级只停止 Vakyu 自己的后台和设置，不会批量关闭聊天软件。已加载旧版拼音组件的应用可能需要重新打开；全局语音使用统一后台。若升级后某个应用仍不能输入，可先保存草稿并完整重开该应用。

## 8. 数据、费用与卸载

语音识别和词卡在本地进行，不上传或保存麦克风录音文件。跟读翻译只将本轮待翻译原文直接发给配置的服务商；开启云联想后还会发送当前拼音与附近文字。API 费用取决于服务商和使用量，本项目不代收翻译费用。

输入日志、个人词库及使用统计保存在本机，可在设置中管理。分享截图、配置或日志前检查是否含有密钥、私人消息等信息。旧数据目录沿用 Qingjian 是为了兼容升级，详见[数据与日志](../help/data-and-logs.md)。

从 Windows「应用和功能」或「已安装的应用」卸载 Vakyu。默认保留个人设置、词库与历史数据，共享的微软运行库也保留。

反馈问题请使用 [GitHub Issues](https://github.com/chenjunqi06-glitch/vakyu-voice-input/issues)，注明 Vakyu 版本、Windows 版本、目标软件及操作步骤。当前是测试版，尚未完成全新 Windows 环境的完整安装与卸载验收；可下载不等于所有电脑或控件均已验证。
