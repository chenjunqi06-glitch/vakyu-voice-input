## 支持范围

Vakyu 的完整 Mac 移植面向 Apple 芯片和 macOS 13 及以上。当前是开发版本，安装包需在 Mac 构建，麦克风、全局按键和各应用填入仍需真机验收。

首次使用从菜单栏 Vakyu 图标进入语音设置。麦克风权限可能显示为“Vakyu”，辅助功能和输入监控可能显示为“Vakyu 语音”；授权后可点“重新检查”立即检查。设置会每 5 秒自动检查权限与快捷键连接状态，自动检查不会申请权限或代替你确认系统提示。密码框、安全输入和不允许辅助功能访问的应用不会自动填入。

打开语音设置后，缺少授权时会优先显示“系统权限”。先点“允许麦克风”，再点“打开辅助功能”，在系统打开的页面启用 Vakyu。应用会自动检查快捷键是否已连接；如果系统仍拒绝连接，再按页面提示开启“输入监控”。

权限列表中找不到 Vakyu 时，把设置页里的“Vakyu 语音应用”卡片拖入系统列表即可；也可点“在访达中显示”定位当前应用，不用查找安装目录。系统提示“退出并重新打开”时，请完成这一步。若开关已打开但仍未通过，可展开页面中的修复说明，用当前应用替换旧项。

如果开关已经打开，却提示“辅助功能权限可能已失效”，请点提示旁的系统设置按钮，移除旧的 Vakyu 语音，再把设置页提供的当前应用重新拖入并启用。开发版更新可能使原授权失效。正式发行应使用固定的开发者签名与公证，减少更新时的身份变化；首次授权仍需由用户在 macOS 系统设置中确认。普通拼音不依赖语音授权。

微信普通聊天框无法开始语音时，请先确认微信已登录并点击聊天输入框。语音设置提供默认开启的“无法读取输入框时直接粘贴”：应用没有提供可读取的输入框时，只在仍是原应用、原窗口且没有安全输入时尝试一次粘贴。录音后请保持原输入位置；关闭此开关会停止尚未执行的受限粘贴。显示“已粘贴，无法核对”时，请检查输入框；若没有文字，可点“复制文字”自行粘贴，不会自动重试或发送消息。不同微信版本是否能填入仍需实际测试。旧版可能将“没有读到输入框”也提示为“密码框不支持”，这不代表聊天框真是密码框；新的提示会区分这两种情况。实际密码框仍不支持语音输入。

微信“设置 → 快捷键”里的“发语音消息”可能占用右 Option。使用包含右 Option 的 Vakyu 跟读组合前，请清除该项，并检查微信自己的“语音输入文字”是否设置了相同按键。这个冲突与普通拼音无法输入是两项不同问题。找不到“读屏优化模式”时，不要反复重新添加 Vakyu 的系统权限；当前微信版本可能没有显示这个入口。

## 按住录音

点要输入文字的输入框，按住左 Option 做普通语音输入，松开直接填入。开启跟读后，按住右 Control＋右 Option 说原话，松开进入口语跟读。录音窗固定在当前屏幕下方、Dock 上方，音量条反映真实麦克风音量。浮窗宽高缩小为原来的一半，标题从开始录音就区分“语音输入”“英语跟读”或“中文跟读”；长句、错误和词卡可在窗口内滚动，操作按钮仍保留。录音没有按固定总时长强制结束的限制。松开普通语音键，或松开跟读组合中的任意一键后，浮窗立即从“正在聆听”变为“正在处理…”，等待识别收尾。按住期间的停顿不会自动结束录音。

跟读快捷键可在语音设置录入，保存后生效，并可恢复默认。普通语音键和跟读键分别显示，不能设成相同入口。普通组合键被系统注册占用时会提示冲突并保留原键。纯修饰键组合，以及其他软件仅在自身窗口内拦截的快捷键，无法完整检测冲突。

支持把跟读键改为 **右 Command＋右 Option**：点“修改跟读键”，按下右侧这两个键再全部松开，显示相应名称后即完成录入。左右侧会分别识别；不支持的纯修饰组合会提示重试，不会保存成单独的 Option。

关闭语音设置或完成快捷键录入后，可直接按住语音键，无需先空按一次。按键触发后若模型尚未就绪，或当前控件不能接收文字，屏幕下方会短暂显示具体原因；提示不会抢走输入焦点，点入正文后可以直接重试。

## 选择学习方向

“启用跟读”默认关闭，关闭时跟读键不启动录音。打开后，使用跟读键需完成翻译句跟读才填入原话；左 Option 普通语音始终直接填入，不进入翻译或跟读。

| 学习英语开关 | 口述 | 跟读 | 填入 |
|---|---|---|---|
| 开启 | 中文 | 英文 | 原中文 |
| 关闭 | 英文 | 中文，配拼音 | 原英文 |

已读单词逐渐变色。短暂停顿、错读或重读后可继续；卡住时可“再试一次”“跳过此词”或“我读对了”。新手容错随本机练习经验逐渐收紧，两个方向分别累计。

点击词语可看本地释义、音标或拼音，播放本机发音。词典无结果会提示，没有额外云查词请求。发音示范暂时停收音，播放完继续，不把示范声当作用户跟读。

点击窗口内外不关闭练习。Esc 取消；完成并成功填入后自动关闭。只填入，不发送消息。若切换应用、修改原输入框或移动光标，按提示回到原目标；填入后会读回原输入框的文字确认结果；网页编辑框使用粘贴方式填入。输入框确认收到完整文字后会尽快结束处理。不能核对完整结果时会保留提示，避免重复插入。

## 费用与性能

语音识别、跟读判定、离线词典和本机朗读不消耗 API token。只有开启跟读后的一次整句翻译使用配置的云服务；可关闭云联想以避免打字时的云请求。录音不会上传。

语音识别使用 CPU，两条计算线程；切换系统音色不需要显卡推理。可在语音设置中选择已安装的英语、中文声音。模型准备完成后显示就绪，准备期间不开始录音。

翻译接口、模型和密钥从输入法设置的“云服务”页填写。关闭云联想也可设置翻译服务。学习资料和密钥留在本机，安装升级保留既有资料。

更新后安装程序会同时启动普通输入法与语音服务。语音能够使用不代表系统当前已选中 Vakyu；要用 Vakyu 拼音打字，请在系统输入法菜单中选择 Vakyu。

安装程序会确认输入源已经启用且能够选择，通过后才报告安装完成。登记失败时会尝试恢复原安装，并保留失败信息；学习资料和云服务配置不会被清除。若提示存在另一个安装位置，请先处理旧副本，避免两份 Vakyu 相互影响。

使用过程中如果系统把 Vakyu 输入法弄丢了（例如在某个应用里选了 Vakyu 又自己跳回别的输入法），Vakyu 会在半分钟内自动重新登记，原本加进输入法菜单的会自动恢复，但不会替你切换当前输入法。语音服务意外停止时也会自动重启，5 分钟内最多 3 次；仍不恢复时再到语音设置里点“重新启动语音服务”。

系统输入法菜单使用有五官细节的小鸡轮廓，随系统明暗外观显示，避免被系统着色成白色方块；图案已针对菜单基线向上校正。应用和语音设置保留彩色小鸡。更新后若仍显示旧图案，可退出登录后重新登录，让系统重新读取输入法。


### 填入失败后找回文字

已确认填入时，语音窗口会自动关闭。如果显示“未能填入”或“请检查填入结果”，窗口会在 3 秒后收起，不需要每次按 Esc。点击 Vakyu 语音菜单中的“复制上次识别文字”可取回原文；开始下一轮前，也可用“查看上次填入结果…”重新打开原窗口并重试。窗口里的“复制”“收起”按钮也可直接操作。

无法确认写入结果时不会重复自动填入，也不会计为跟读成功。按住语音快捷键可以结束上一轮失败会话并开始新录音；录音中、翻译中或正常跟读中不会因这个收起计时器被中断。上次识别文字只保留在本次运行的内存中，退出语音程序后清除。
