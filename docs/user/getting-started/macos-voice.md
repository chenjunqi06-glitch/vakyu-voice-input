## 支持范围

Vakyu 的完整 Mac 移植面向 Apple 芯片和 macOS 13 及以上。当前是开发版本，安装包需在 Mac 构建，麦克风、全局按键和各应用填入仍需真机验收。

首次使用从菜单栏 Vakyu 图标进入语音设置，允许麦克风、辅助功能和输入监控。授权由 macOS 管理。密码框、安全输入和不允许辅助功能访问的应用不会自动填入。

## 按住录音

点要输入文字的输入框，按住左 Option 做普通语音输入，松开直接填入。开启跟读后，按住右 Control＋右 Option 说原话，松开进入口语跟读。录音窗固定在当前屏幕下方、Dock 上方，音量条反映真实麦克风音量。录音没有按固定总时长强制结束的限制。

跟读快捷键可在语音设置录入，保存后生效，并可恢复默认。普通语音键和跟读键分别显示，不能设成相同入口。普通组合键被系统注册占用时会提示冲突并保留原键。纯修饰键组合，以及其他软件仅在自身窗口内拦截的快捷键，无法完整检测冲突。

## 选择学习方向

“启用跟读”默认关闭，关闭时跟读键不启动录音。打开后，使用跟读键需完成翻译句跟读才填入原话；左 Option 普通语音始终直接填入，不进入翻译或跟读。

| 学习英语开关 | 口述 | 跟读 | 填入 |
|---|---|---|---|
| 开启 | 中文 | 英文 | 原中文 |
| 关闭 | 英文 | 中文，配拼音 | 原英文 |

想把英文发出去、顺便练口语时，打开“读完发出英文”：说中文 → 跟读英文 → **填入英文**（学习中文时是说英文 → 跟读中文 → 填入中文）。

桌面右上角有一个可拖动的快捷浮窗，上面有“跟读”“发英”两个按钮：点亮一个就开启对应方式，再点同一个关闭，不用进设置。菜单栏 Vakyu 图标的菜单里也有同样的开关，以及“显示快捷浮窗”。

已读单词逐渐变色。短暂停顿、错读或重读后可继续；卡住时可“再试一次”“跳过此词”或“我读对了”。新手容错随本机练习经验逐渐收紧，两个方向分别累计。

点击词语可看本地释义、音标或拼音，播放本机发音。词典无结果会提示，没有额外云查词请求。发音示范暂时停收音，播放完继续，不把示范声当作用户跟读。

点击窗口内外不关闭练习。Esc 取消；完成并成功填入后自动关闭。只填入，不发送消息。若切换应用、修改原输入框或移动光标，按提示回到原目标；不能核对结果时会保留提示，避免重复插入。

## 划词翻译（右键「用 Vakyu 翻译」）

在任何软件里选中文字后右键，选“服务 → 用 Vakyu 翻译”（服务较少时会直接出现在右键菜单里），鼠标旁弹出译文小窗：中文译成英文，英文和其他外语译成中文；点“复制译文”写入剪贴板，点窗外任意处或 × 关闭。只读取选中的文字，不会改动原文，也不占用剪贴板。

第一次安装或升级后菜单里没有这一项时，注销再登录一次；仍没有就到“系统设置 → 键盘 → 键盘快捷键 → 服务 → 文本”里勾选“用 Vakyu 翻译”，也可以在那里给它设一个快捷键。翻译使用 macOS 系统翻译，完全在本机运行、免费（见下一节）。

## 费用与性能

语音识别、跟读判定、离线词典、本机朗读以及跟读和划词翻译都在本机进行，不联网、不需要 API 密钥。翻译使用 macOS 系统翻译，需要 macOS 15 及以上；第一次使用前，到“系统设置 → 通用 → 语言与地区 → 翻译语言”下载“中文（简体）”和“英语”，之后离线可用，没下载时会提示这一步。macOS 13、14 没有系统翻译，可以使用普通语音，但不能跟读或划词翻译。录音和待翻译的文字都不会上传。

语音识别使用 CPU，两条计算线程；切换系统音色不需要显卡推理。可在语音设置中选择已安装的英语、中文声音。模型准备完成后显示就绪，准备期间不开始录音。

翻译接口、模型和密钥从输入法设置的“云服务”页填写。关闭云联想也可设置翻译服务。学习资料和密钥留在本机，安装升级保留既有资料。
