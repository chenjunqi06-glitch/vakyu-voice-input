## 中英切换

- **macOS**：`Caps Lock`（键盘上的中 / 英键），熄灭为中文，亮起为英文。
- **Windows**：单击 `Shift`（按下即松开，不与其他键组合），任务栏右下同步显示「中」或「英」，Caps Lock 亮着时显示「A」；点击该图标同样可以切换。
  Windows 上的 `Caps Lock` 只控制大小写。

英文模式下的行为见 [英文模式](../input/english-mode.md)。

## 候选窗口

输入拼音时，候选窗口显示在光标下方：顶部一行是已输入的拼音（自动按音节分隔），其下是候选，右下角是页码。缺省竖排，每页 9 个，均可在设置中修改。
候选右侧字号较小、颜色较浅的一列是译词，见 [译词与生词](../learning/translation.md)。

## 整句输入

无需切换模式，连续输入整句后再上屏：`jintiantianqihenhao` 的首选即为「今天天气很好」。简拼同样可用：`jttqhh`。
两三个字母的简拼通常仍按词处理（`sj` 时间），需要整句时请多输入几个音节。

## 说中文，练英语（Windows）

普通语音输入：先点输入框，按住 Alt 说中文，松开后自动填入原输入框，不会替你发送。可在 **设置 → 快捷键** 修改语音键和启动灵敏度。

英语跟读是可选功能，默认关闭。先在「设置 → 云服务」配置翻译服务，再打开 **设置 → 快捷键 → 英语跟读练习**：

1. 按住语音键说一句中文，再松开；中文暂不填入。
2. 看中文下方的英文译句，先听一遍示范。新手阶段示范语速较慢，播放时麦克风关闭。
3. 等“正在录音”出现后，跟着当前词提示读完整句。词语由浅变深，完成后原中文才会填入，发送仍由你决定。

不想先听示范，可关闭“跟读示范朗读”；想结束本轮，按 `Esc`。练习从新手等级开始，完成后积累经验，逐渐提高要求；取消或失败不扣分。等级按本机当前 Windows 用户的完成进度保存，颜色提示只是识别文字匹配，不是发音评分。

详细按键、升级规则和适用范围见 [英语跟读练习](keys.md#英语跟读练习)。

录音音波反映实际麦克风音量。跟读时可看“刚听到”确认识别器听成了什么，再从下划线词继续；新手模式兼容常见口音和中文人名的拼音拆词，数字、否定和句子内容仍需读全。

## 常用按键

| 操作 | 按键 |
|---|---|
| 上屏首选（或高亮候选） | `Space` |
| 上屏第 N 个候选 | 数字 `1` 至 `9` |
| 将拼音字母原样上屏 | `Enter` |
| 翻页 | `[` `]`，或 `PageUp` / `PageDown` |
| 移动高亮 | `↑` / `↓` |
| 删除一个字母 | `Backspace` |
| 清空 | `Esc` |

完整按键表（两个平台并列）见 [按键与快捷键](keys.md)。

## 中文标点

未输入拼音时，中文模式下输入 `, . ? ! : ; ( ) [ ] < > \ ^ _ $ ~` 得到全角标点，`"` `'` 成对切换；数字之后的 `.` 保持半角（`3.14`）。
输入拼音过程中输入标点会先上屏当前高亮候选，再输出标点；没有中文候选时才进入英文直输，见 [快捷输入](../input/shortcuts.md#中英混输)。

Windows 上可关闭全角转换：「设置 → 通用」的「中文模式标点转全角」，或点击悬浮状态条上的「，。」格。英文模式另有一份设置，缺省半角；需要全角时在英文模式下点击该格，或打开「英文模式标点转全角」。

## 选错了词

上屏后用 `Backspace` 删除，再输入同一段拼音改选其他候选，上一次记录的学习会被撤销；误按 `Space` 选中错词不会被输入法记住。
连续删除后面几个词再从头重输同样有效：删除「沃德书」后重输为「我的书」，「沃德」那次选择视为未发生。

一段拼音分几次选完（先选一个字，剩余部分整句上屏），第二次以同样方式输入时，合起来的词会被记为用户词，此后整段输入直接排在第一位。
