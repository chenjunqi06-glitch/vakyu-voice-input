- **macOS**：从输入法菜单打开（菜单栏「中 / 英」状态项，或系统输入源菜单中 Miracle 的几项），名为「偏好设置」。
- **Windows**：开始菜单的「Vakyu 设置」、任务栏小鸡图标的右键菜单，或悬浮状态条上的 ⚙。

Windows 的任务栏和托盘使用方形小鸡图标；设置侧栏展示完整的 Vakyu 字母与小鸡标志，沿用紫色渐变主题和白色文字。

Windows 设置窗口去掉系统外边框和独立标题栏，顶部与紫色背景连成一体。拖动顶部空白处可移动窗口，右上角保留最小化、最大化或还原、关闭按钮；窗口边缘仍可调整大小。

Windows 搜索若仍显示旧绿色图标，是搜索保存了旧图片。组件更新会刷新 Vakyu 的搜索图标；更新后关闭搜索面板再打开即可查看。

Windows 悬浮状态条左上角展示完整 Vakyu 标志，上半露出边框、下半在框内。标志下方保留中英文、标点和设置按钮；拖动标志也可以移动状态条，单击标志不会切换输入状态。

常规设置修改即时生效；自定义短语的启用开关即时生效，新增或编辑在点击「保存规则」后生效。

安装或首次登录会将 Vakyu 添加到当前用户的输入法切换列表，保留默认键盘与其他输入法。以后主动从 Windows 设置中移除 Vakyu，普通后台启动不会反复加回来；重新运行安装包会重新启用。若 Win＋空格仍没有 Vakyu，可在 Windows「时间和语言 → 语言和区域 → 中文（简体）→ 语言选项 → 键盘」添加 Vakyu；没有中文语言项时先添加中文。此过程失败的说明会写入 Vakyu 日志，普通语音仍可独立使用。

### 跟读方向（Windows）

在「快捷键」页先打开 **启用跟读练习 / Reading practice**，再用独立的 **学习英语 / Learn English** 开关选择方向：

| 学习英语开关 | 练习流程 |
|---|---|
| 开启（默认） | 口述中文 → 显示英文译句 → 跟读英文 → 填入原中文 |
| 关闭 | Speak English → 显示中文译句与拼音 → 跟读中文 → 填入原英文 |

完成后只填入原文，不会自动发送。关闭“学习英语”会切换到学中文；要恢复普通中文语音，请关闭“启用跟读练习”总开关。两个方向共用已保存的跟读快捷键（支持 `右 Ctrl + 右 Alt`），切换立即生效并会取消尚未完成的一轮。英语和中文的等级、经验分别保存。

两个方向复用本机中英语音识别，示范和词语发音使用系统对应语言的声音，不额外加载模型或要求显卡。点击英文词查看中文词义与可用音标，点击中文词查看英文词义与拼音；查询只使用本地词表，支持常见英文词形，未收录的生僻词或人名会提示无结果。

跟读中已通过的词在本轮内保留，后续读错或识别回改不会把它们变回未通过。可以直接补读剩余部分，或点“继续补读”重新收音；只有主动点“整句重读”才从头练习。补读和整句重读均使用现有译文，不增加翻译费用，也不需要额外开启设置。

跟读只为每段口述文字发起一次翻译请求，词卡没有额外 API 费用；语音识别和词卡查询不上传录音。原有 `[shortcut] voice_english_practice` 控制是否启用跟读；新增 `voice_practice_learn_english` 默认 `true`，设为 `false` 学中文。两项都会保留到下次启动，详细操作见 [按键与快捷键](../getting-started/keys.md#中英跟读练习)。

### 繁体输出

打开「繁体输出」后，候选与上屏文字按 OpenCC 转成繁体（只换字形，不换用语：软件 → 軟件）。云端词与整句补全同样转换。引擎内部仍按简体处理：用户词、词频、输入统计与输入日志都记简体，译词照常显示。

## 横排与拼音位置

横排时候选排成一行，仅高亮候选在下方单独一行显示译词，页码在行尾。
macOS 上可以把这一行展开成多行：先在「候选窗口」页的排布下面勾选「横排时 ↑ / ↓ 展开成多行」（缺省不勾，不勾时横排下的按键与以前一样：
`↑` / `↓` 逐个移动高亮，`←` / `→` 移动拼音光标，`Esc` 清空）。勾选后立即生效：
按 `↑` / `↓` 会把这一行展开成 6 行的矩阵（一行对应一页候选），同时换到上一行或下一行；`←` / `→` 改为在候选之间移动（没展开时也是，拼音光标改用 `⌥ + ←` / `⌥ + →`），
数字键选的是高亮所在那一行的第几个，高亮移出矩阵上下边缘时按行滚动，翻页键一次翻一屏。展开后窗口大小在这一轮输入里保持不变；超过四个字的候选在格子里截断显示为「…」，
高亮到它时矩阵下方给出完整内容。继续输入拼音或按 `Esc` 收回单行。
「只在窗口」显示拼音适用于终端与部分 Electron 应用，这类应用对行内拼音的渲染效果较差。

## 输入法菜单（macOS）

云联想开关、模糊音子菜单、偏好设置、打开日志目录、版本号。配置文件解析失败时增加一条灰色的错误说明，此时沿用上一份可用的配置，输入法不退出。

## 直接修改配置文件

全部设置保存在一个配置文件中，「高级」页有「在编辑器中打开配置文件」，文件内每一项均附说明。保存后一秒内生效，无需重新切换输入法。

## 自定义短语（macOS）

「自定义短语」页以常驻表格显示启用状态、内容和固定候选位置，可直接勾选启用或停用。点击「+」新增，双击已有行或点击「编辑…」修改，选中后点击「−」删除。新增或编辑时，填写 1–32 个小写英文字母的输入码、1–9 的候选位置和文本，点击「保存规则」。文本可以包含空格、换行、地址、长回复或标点，按原样输出；候选窗口只展示长文本的简短预览。

例如将 `ee` 的第 1 位设置为 `：`，第 2 位设置为 `；`，输入 `ee` 后按空格选择首项，按 2 选择第二项。普通拼音候选填入其他位置，学习与模型重排不会改变自定义位置；云端词只使用不影响固定位置的剩余格。若固定位置超过第一页容量（例如第 9 位、每页 5 项），本次查询不显示云端词。位置跨页时按当前页的序号选择。

同一个输入码的位置不能重复，新增和编辑冲突时提示并拒绝保存；停用规则也保留其位置。没有足够普通候选时保留空位，空位不能上屏。选择已有规则后可编辑、停用或删除。

编辑期间若规则被其他窗口或外部文件修改，保存会提示并保留草稿，不覆盖新规则。保存会保留现有短语条目的注释。

默认中文标点模式会保存，重启后仍生效；选择半角不会改变自定义短语中的全角标点。英文模式不触发自定义短语。

### 系统的文本替换

「自定义短语」页勾选「也使用系统设置『键盘 → 文本替换』里的条目」（缺省勾选）后，系统文本替换中的条目在输入拼音时同样可用：
输入码敲全后短语出现在该输入码最靠前的空位（页里的规则优先占位），`Space` 或数字键上屏。
只有输入码全为小写英文字母的条目可用；系统设置中新增或修改的条目在下次切换到 Miracle 时生效。它们不在页里的表格中列出，要改请到系统设置。

Windows 竖排候选框左下角显示完整标志。多页候选时标志与页码共用底部空间，减少最后一个候选词下方的留白。
