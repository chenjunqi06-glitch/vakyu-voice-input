# Vakyu Mac 构建 9 验收记录

构建版本：0.1.5-dev-unknown，CFBundleVersion 9，arm64。最低系统 macOS 13；本次实际验证环境为 Apple Silicon / macOS 26.4.1。

## 本次语音修复

- 配置 `[shortcut].voice_paste_fallback` 默认为 true，设置页可关闭。
- 对无法读取的输入框保留原前台 PID 与窗口标识，投递前重新核对；密码、安全输入、权限不可用或上下文变化时拒绝。
- 受限粘贴只发送一次 Cmd+V，沿用事件标记和剪贴板保存／恢复；不发送回车。显示“已粘贴，无法核对”，保留复制文字入口，不重复注入。
- 可读输入框继续使用原草稿、选区和精确读回验证。
- 新增辅助功能可能失效提示和固定签名身份优先选择；本机无可用固定证书，当前构建仍为临时开发签名。

## 验证结果

- Rust：`cargo test --locked -p vakyu-voice-service -p qingjian-macos -p qingjian-platform`，101 项通过。
- Swift：生产代码编译通过；基于真实生产代码及测试方法的本地内存回放 57 个方法、289 条断言通过。
- `swift test --package-path apps/macos/companion --jobs 2` 已执行，但本机构建工具缺少 XCTest，未通过；不能将断言回放写成 XCTest 通过。
- 安装后深度严格签名校验、资源／运行时检查及独立输入源登记核验通过。已重新授予麦克风、辅助功能和输入监控；快捷键监听及模型就绪。
- 用户分别确认：TextEdit 已填入且没有自动回车；Safari 浮窗有 Vakyu 标识，文字填入且未回车；微信聊天框文字填入且没有自动发送。
- 新版实测未捕获对应触发日志，不能认定微信必然走了受限粘贴路径；实际体验结论以用户反馈为依据。
