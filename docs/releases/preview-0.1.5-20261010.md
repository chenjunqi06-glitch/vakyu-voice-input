# Vakyu Voice Input 0.1.5 Preview · Windows 语音输入与中英跟读

这是 Vakyu 的首次公开 Windows 测试版。它把本地语音输入、中文输入法和中英口语跟读放在一起：按住说话，松开输入；也可以选择先完成一轮自己的句子练习。

## 下载安装

在本页 Assets 下载 **`vakyu-0.1.5-dev-20261010-startup-windows-x86_64-setup.exe`**。适用于 Windows 10 22H2 / Windows 11 的 Intel、AMD x64 电脑。安装包约 250 MB，包含语音模型、Python、词典和所需运行库，不需要自行安装开发工具。

安装时按提示授权管理员权限，完成后在开始菜单搜索「Vakyu 设置」。普通语音无需 API 密钥；首次启动先等待本机模型就绪，并允许桌面应用访问麦克风。

本次公开安装包没有可信发布者代码签名，可能出现 SmartScreen 或未知发布者提示。请核对下载仓库和 `SHA256SUMS.txt`；公司管理策略可能限制安装。无需关闭系统安全功能。

## 开始使用

| 想做什么 | 操作 |
|---|---|
| 普通语音转文字 | 点输入框，按住 **左 Alt** 说话，松开后填入文字 |
| 用中文练英语 | 设置自己的翻译 API，启用跟读；按住 **右 Ctrl + 右 Alt** 说中文，松开后读英文 |
| 用英文练中文 | 关闭「学习英语」方向开关，再使用跟读快捷键；中文配拼音和英文词义 |
| 取消本轮 | 按 **Esc** |
| 使用拼音输入法 | 按 **Win + Space** 选择 Vakyu |

跟读默认关闭。翻译 API 可在设置中的「云服务」配置，**不必开启云联想**。读完只填入原文，发送由用户操作。完整教程见仓库首页的「详细使用教程」。

## 本版亮点

- 本地 CPU 流式语音识别，普通语音不上传录音、不消耗 API token，不要求独立显卡。
- 中英双向跟读；已读单词保留进度，支持补读、跳过、手动确认与整句重读。
- 本地词典与系统朗读，点词可查可用词义、音标或拼音。
- 普通语音和跟读使用独立、可配置的快捷键。
- 紫色界面、麦克风音量预览、托盘快捷入口与个人词频学习。
- 后台静默启动、恢复启动去重与托盘生命周期修复。

## 费用、隐私与兼容性

普通输入、识别、补读、离线查词和系统朗读在本机处理。跟读翻译会把本轮原文发给你配置的 API 服务商，并按该服务商规则计费。云联想默认关闭；安装包不包含作者的 API 密钥或免费额度。

本版是预览版。分发校验、模型握手和开发机验证已完成，尚未完成全新 Windows 虚拟机的完整安装、卸载验收。不能保证每个应用控件都能接收输入；管理员程序、密码框、系统安全界面和部分自绘控件存在限制。当前仅支持一个交互登录会话，不支持 Windows ARM 或 32 位 Windows。

macOS 移植源码仍需 Mac 编译与真机验收，本次不提供 macOS 或 iOS 安装包。
