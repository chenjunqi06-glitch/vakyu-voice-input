# Vakyu Voice Input 0.1.5 Preview 3 · 快捷键与后台稳定性

本版同步当前 Windows 开发版，重点改进普通语音和英语跟读快捷键的保存、触发与后台生命周期。已有用户可直接运行完整安装包升级，配置和个人词库会保留。

## 下载与安装

在本页 Assets 下载 **`vakyu-0.1.5-dev-20261012-trigger-hotkey-windows-x86_64-setup.exe`**。安装包包含语音模型、Python、词典、设置程序和所需运行库，不需要先安装 Rust、Python 或上一版。

支持 Windows 10 22H2 / Windows 11 原生 x64（Intel / AMD）。安装后从开始菜单打开「Vakyu 设置」，按 `Win + Space` 选择 Vakyu 输入法；普通语音后台会随用户登录启动。

## 本版改进

- 同步当前源码中的全局语音触发、后台生命周期和设置快捷键实现。
- 普通语音与英语跟读快捷键分别保存，并在设置中检查与另一功能的冲突；后台无法确认时保留原设置并提示原因。
- 继续包含上一版的通用中文词频学习，以及中文夹英文普通语音的本地弱英文提示。
- 普通语音使用本机 CPU，不需要显卡、API 密钥或云端语音额度；词频学习和英文提示不增加 API token。

## 使用

普通语音：点击文本框，按住左 Alt 说话，松开后填入文字。英语跟读：在设置中启用跟读并配置自己的翻译 API，按住右 Ctrl + 右 Alt 说原文，读完译文后填入原文。快捷键可以在设置中重新录入；保存失败时不会覆盖原快捷键。两种模式都只填入，不自动发送，按 Esc 可取消。

## 验证与限制

本版公开包包含 1,466 个文件，总大小 518,892,106 字节；清单、哈希、架构、`uiAccess=false`、凭据扫描和默认配置检查通过。随包语音运行时在空用户目录中完成 Ready → Shutdown，未打开麦克风。完整范围和手动清单见 `VALIDATION.md`。

这是 Windows 预发布版。尚未完成全新 Windows 的完整安装、卸载和真实麦克风全套验收；管理员程序、密码框、受保护界面和部分自绘控件可能限制填入。公开包没有可信发布者代码签名，Windows 可能显示安全提示。不支持 Windows ARM、32 位 Windows 或多个用户同时交互登录。本次不提供 macOS / iOS 安装包。
