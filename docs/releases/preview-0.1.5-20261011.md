# Vakyu Voice Input 0.1.5 Preview 2 · 词频学习与中英混说改进

本版更新中文候选词的个人排序和普通语音中的英文词汇提示。已有用户可直接运行新版完整安装包升级，个人配置和词库会保留。

## 下载与安装

在本页 Assets 下载 **`vakyu-0.1.5-dev-20261011-personal-input-windows-x86_64-setup.exe`**。这是包含模型、词典、Python 和所需运行库的完整安装包，新电脑也可使用，不需要先装上一版或开发工具。

支持 Windows 10 22H2 / Windows 11 的 Intel、AMD x64 电脑。运行安装包，按提示授权管理员权限，安装完成后从开始菜单打开「Vakyu 设置」。拼音输入使用 `Win + Space` 切换到 Vakyu；普通语音只需后台运行、麦克风权限开启并等待模型就绪。

## 本次改进

- **通用中文词频学习**：适用于中文单字和词组，不是针对某个词的特例。通过简拼、尚未打完的拼音、纠错或模糊音选词时，也会记住该词对应完整拼音的偏好。常选词在对应候选中优先排序，误选后退格改词会撤回相应学习，不把多音字的不同读音混为一谈。
- **空闲时保存习惯**：已有后台定时任务会保存变化的学习数据，减少最后一次选词后不再输入而未及时落盘的情况，不增加轮询线程。
- **改善中文夹英文的普通口述**：在现有中英语音模型中加入弱英文词汇提示，包含常用软件/工作词汇；开启个人学习时，还会参考已提交的常用英文词。它帮助模型保留英文，不把识别出的中文强行替换成英文。
- **保持本地、低开销**：不下载新模型、不增加第二份模型或显卡计算、不增加云请求及 API token。个人词汇提示在本机处理；关闭个人学习后，下一次录音不再使用个人词表。跟读提示与普通口述提示相互隔离。

## 使用方法

| 功能 | 操作 |
|---|---|
| 个人词频学习 | 在设置中保持「学习输入习惯」开启，正常选择你常用的中文候选词；以后对应拼音会参考你的使用频率 |
| 普通语音输入 | 点击输入框，按住 **左 Alt** 说话，松开后填入识别文字；可说中文夹英文 |
| 英语或中文跟读 | 按需启用跟读并配置自己的翻译 API，按住 **右 Ctrl + 右 Alt** 说原文，松开后跟读译文 |
| 取消本轮 | 按 **Esc** |

以上均只填入，不自动发送消息。普通语音不需要 API；跟读翻译仍按用户配置的服务商计费。完整设置说明见 [快速上手](https://github.com/chenjunqi06-glitch/vakyu-voice-input/blob/main/docs/user/getting-started/vakyu-quickstart.md)。

## 验证与边界

中文候选学习经过真实学习器、重载持久化和 CLI 回归；普通语音提示经过单元测试及固定合成音频对比。24 条混说样本的目标英文关键词保留由 23/24 变为 24/24；这不是整句准确率，也不代表真人口音都能准确识别，未知专名仍可能出错。详细实际检查与手动验收见附件 `VALIDATION.md`。

本版继续作为预发布提供。尚未完成全新 Windows 的完整安装、卸载和真实麦克风验收；不保证所有应用控件兼容。公开包使用 `uiAccess=false`，不安装开发者证书，没有可信的公开代码签名，Windows 可能显示安全提示。管理员权限窗口、密码框和受保护控件存在限制。安装器不会批量关闭聊天软件和浏览器，已加载旧输入法组件的程序可能需重开。

不支持 Windows ARM、32 位 Windows 或多个用户同时交互登录。本次不提供 macOS / iOS 安装包，macOS 移植仍需原生验收。
