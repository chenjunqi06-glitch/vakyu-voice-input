安装完成

点菜单栏的输入法图标，选「Vakyu」就能用了。

如果列表里没有：

  1. 系统设置 → 键盘 → 输入法 → 编辑… → 左下角「+」→ 简体中文 → Vakyu。
  2. 还没有的话注销再登录一次，系统会重新扫描输入法目录。

语音宿主会自动启动并随登录启动。首次使用按语音设置顶部引导允许麦克风与辅助功能；按钮会直接打开对应设置，缺少应用时可以拖入。若快捷键仍未连接，页面会提示开启输入监控。右 Option 对应 Windows 右 Alt，右 Control＋右 Option 也可在设置中录入。

偏好设置在输入法菜单里；卸载运行 /Library/Input\ Methods/Vakyu.app/Contents/Resources/uninstall.sh（加 --purge 连学习数据一起删）。

遇到问题请把「~/资源库/Logs/Qingjian/」里当天的日志和偏好设置「关于」页复制的诊断信息发给作者。
